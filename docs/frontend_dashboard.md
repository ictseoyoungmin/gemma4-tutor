# Frontend Dashboard And Learner Workspace

This folder contains a lightweight React + Vite frontend scaffold for the competition demo.

The frontend now has two distinct surfaces:

- Dashboard: learner progress, ready quiz packs, achievements, and background-job visibility
- Learner Workspace: a dedicated study surface for tutor chat, practice flow, image learning, and audio learning

## Current implemented panels
- Dashboard overview cards
- Skill snapshot table
- Background queue panel
- Ready quiz pack list
- Achievement cards
- Placeholder roadmap section
- Learner workspace hero and study-flow framing
- Learner tutor chat placeholder
- Learner practice-flow placeholder
- Learner image-study placeholder
- Learner audio-study placeholder

## Deferred placeholder panels
- Real chat transcript UI
- Single-item TOEIC question flow
- Answer submission and explanation loop
- Image upload lesson UI
- Writing correction workspace
- Audio/TTS controls
- Admin evaluation console
